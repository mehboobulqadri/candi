# Phase 06 — v0.9 (Advanced Rendering, open-ended)

## Goal

Optional terminal image protocols and advanced page rendering (workflow Phase 8).
Entry: v1.0 candidate shipped and stable. Intentionally open-ended, lowest
priority.

## What gets built

- Spike 5 first — terminal image protocol survey (Kitty, Sixel, iTerm2, Braille /
  half-block fallback).
- Optional Kitty/Sixel/Braille rendering backends in the TUI.
- Dark/warm page rendering transforms (contrast, brightness, warmth) — applied to
  rendered pages, not just extracted text.

## Exit criteria (workflow Phase 8)

- Defined per-feature; this phase is intentionally open-ended and lowest priority.
