# Candi

A minimal, fast, cross-platform document reader with a TUI and GUI sharing one native core.

> Make reading documents fast, comfortable, and distraction-free.

## Documents

- [Project](project.html) — what Candi is, its goals, non-goals, and phased requirements
- [Requirements](REQUIREMENTS.html) — the functional and non-functional requirements specification
- [Spikes & Options](spikes.html) — the resolved and open technical decisions, the options for each, and the PDF-backend spike results
- [Workflow](workflow.html) — the end-to-end procedure from setup through v1.0 distribution, with entry/exit criteria and decision gates per phase
- [Architecture](architecture.html) — the shared native core, crates, frontends, themes, configuration, and security model
- [Publishing](publishing.html) — how this docs site is published with GitHub Pages

## Design Principle

Every feature is evaluated against one question:

> Does this make reading better without making Candi unnecessarily complicated?
